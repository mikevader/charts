## Changelog

### Version 1.6.0

#### Added

- Optional Prometheus metrics via `metrics.enabled`, which turns on FlareSolverr's built-in exporter and adds a `metrics` service, a ServiceMonitor and a PrometheusRule with `FlareSolverrAbsent` and `FlareSolverrHighErrorRate` alerts.

#### Changed

- The built-in exporter (`PROMETHEUS_ENABLED`/`PROMETHEUS_PORT`) is no longer turned on by default. Set `metrics.enabled=true` to keep it.
