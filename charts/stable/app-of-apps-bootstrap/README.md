## Custom configuration

The chart is the root of an Argo CD app-of-apps setup. For every entry in `bootstrap` it renders a
parent `Application` named `<name>-apps` that deploys the [app-of-apps](../app-of-apps) chart at
`path` in `repository`, with the group's values file `<name>.yaml`.

```yaml
repository: https://github.com/mikevader/k3s-cluster-infra-apps.git
bootstrap:
  - name: cluster-init-apps
  - name: cluster-platform-apps
```

| bootstrap | list | `[]` | App groups to create a parent Application for. Each entry renders the Application `<name>-apps` with the values file `<name>.yaml`. |
| path | string | `"apps-root-config/applications"` | Path of the app-of-apps chart and its group values files in `repository` |
| repository | string | `""` | Git repository holding the app-of-apps chart and the group values files |
